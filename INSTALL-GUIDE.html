دليل نشر وتثبيت تطبيق BioSense–Math

تطبيق ويب قابل للتثبيت (PWA) — محاكاة تفاعلية + لوحة قيادة تشغيلية — عربي/إنجليزي — يعمل دون إنترنت

ما الذي تحصل عليه

وضع المحاكاة
تحكّم مباشر في المعاملات الأحد عشر والشروط الابتدائية، سلاسل زمنية، مستوى الطور H–B، طيف اليعقوبي، مخطط التشعّب في β مع غلاف الدورة الحدّية، وحساب فوري لـ R₀ وعتبة هوبف β_H وهامش الأمان.
لوحة القيادة التشغيلية
إدخال يدوي لقراءات الحسّاسات الخمسة (حرارة، رطوبة، ضوئي، pH، تدفق) أو للمتغيرات مباشرة، معايرة قابلة للتعديل، مؤشر إنذار بثلاثة مستويات مع أسبابه، إشارات إنذار مبكر (التباين والارتباط الذاتي)، تنبؤ بالمسار وزمن بلوغ حد الإنذار، تقدير المعاملات من السجلّ، سجلّ قراءات مع تصدير CSV وتقرير قابل للطباعة.
ثنائي اللغة
زر واحد يبدّل بين العربية والإنجليزية مع عكس كامل للاتجاه (RTL/LTR)، ومظهر فاتح/داكن.
يعمل دون إنترنت
بعد أول فتح يُخزَّن التطبيق كاملاً على الجهاز عبر Service Worker، ولا تغادر أي بيانات جهازك.

الطريقة ١ نشر فوري خلال دقيقة — Netlify Drop

أسرع طريقة للحصول على رابط HTTPS قابل للتثبيت، بدون تثبيت أي برنامج وبدون حساب مطوّر.

1
فُكّ ضغط الملف biosense-math-app.zip على حاسوبك.
2
افتح https://app.netlify.com/drop في المتصفح.
3
اسحب المجلد biosense-pwa كاملاً وأفلته داخل الصفحة (أو اسحب ملف ZIP مباشرة).
4
خلال ثوانٍ يظهر رابط مثل https://tender-owl-123456.netlify.app — هذا هو رابط التثبيت.
5
افتح الرابط على الجوال وثبّته (انظر الجدول أدناه). يمكنك تغيير الاسم من Site settings → Change site name إلى شيء مثل biosense-math.
لمشاركة الرابط مع الجوال بسرعة: أرسله لنفسك عبر أي تطبيق مراسلة، أو أنشئ رمز QR له من أي موقع لتوليد QR.

الطريقة ٢ رابط دائم مجاني — GitHub Pages

مناسب للنشر الأكاديمي المستقر وربط التطبيق بالورقة البحثية.

  1. أنشئ حساباً على github.com إن لم يكن لديك، ثم مستودعاً جديداً عاماً باسم biosense-math.
  2. ارفع محتويات مجلد biosense-pwa (وليس المجلد نفسه) عبر زر Add file → Upload files، أو عبر الطرفية:
cd biosense-pwa
git init
git add .
git commit -m "BioSense-Math PWA"
git branch -M main
git remote add origin https://github.com/USERNAME/biosense-math.git
git push -u origin main
  1. في المستودع: Settings → Pages → Source: main / (root) → Save.
  2. بعد دقيقة يصبح الرابط جاهزاً: https://USERNAME.github.io/biosense-math/
تأكد أن ملف index.html في جذر المستودع مباشرة، وليس داخل مجلد فرعي، وإلا فلن يعمل الرابط.

الطريقة ٣ تجربة محلية على حاسوبك

cd biosense-pwa
python3 -m http.server 8000
# ثم افتح: http://localhost:8000

localhost يُعامل كسياق آمن، لذا يعمل التثبيت والعمل دون إنترنت أثناء التجربة على نفس الحاسوب. أما التثبيت من الجوال فيتطلب رابط HTTPS (الطريقتان ١ أو ٢).

الجهازالخطوات

بعد التثبيت تظهر أيقونة التطبيق على الشاشة الرئيسية/سطح المكتب، ويفتح بنافذة مستقلة بلا شريط عنوان، ويعمل كاملاً دون إنترنت.

ملاحظات تشغيلية

  • التحديث: عند تعديل أي ملف، غيّر رقم الإصدار في أول sw.js (مثلاً bsm-v1.0.3) ثم أعد النشر؛ سيلتقط المتصفح النسخة الجديدة تلقائياً.
  • الخصوصية: جميع الحسابات داخل المتصفح، ولا تُرسل أي بيانات إلى أي خادم. سجلّ القراءات محفوظ محلياً على الجهاز.
  • مشاركة حالة معيّنة: زر «نسخ رابط الحالة» ينتج رابطاً يتضمن كل المعاملات والشروط الابتدائية، مفيد لمشاركة سيناريو مع زميل أو لإدراجه في ورقة أو محاضرة.
  • التقرير: زر «تقرير قابل للطباعة» في لوحة القيادة ينتج صفحة تقرير (حالة، R₀، β_H، الإنذار، سجلّ القراءات) يمكن حفظها PDF من نافذة الطباعة.

English — quick reference

Installable PWA implementing the BioSense–Math five-compartment cellular-stress model: interactive simulation + operational dashboard, Arabic/English with full RTL/LTR, works fully offline.

Publish

  • Fastest: drag the biosense-pwa folder onto https://app.netlify.com/drop → instant HTTPS link.
  • Permanent: push the folder contents to a GitHub repo → Settings → Pages → main / (root) → https://USERNAME.github.io/biosense-math/
  • Local: python3 -m http.server 8000 → http://localhost:8000

Install

  • Android/Chrome: “Install app” button, or ⋮ → Install.
  • iOS/Safari: Share ⬆ → Add to Home Screen.
  • Desktop Chrome/Edge: ⊕ icon in the address bar → Install.

Model

H' = a·H·(1 − H/K) − β·B·H
S' = β·B·H − (γ + μ)·S + η·R
D' = μ·S − δ·D
B' = λ·D − θ·B
R' = σ·H − ρ·R        R₀ = β·K·μ·λ / [(γ + μ)·δ·θ]
